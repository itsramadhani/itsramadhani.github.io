# Muhammad Ramadhani - Portfolio

A modern portfolio website built with Next.js 14, TypeScript, and Vercel Speed Insights.

## Features

- ⚡ Built with Next.js 14 App Router
- 📊 Vercel Speed Insights integration for performance monitoring
- 🎨 TypeScript for type safety
- 📱 Responsive design
- 🚀 Optimized for production with static export

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

To create a production build:

```bash
npm run build
```

This will generate a static export in the `out` directory.

## Speed Insights

This project includes Vercel Speed Insights to monitor and optimize website performance. The SpeedInsights component is configured in the root layout (`app/layout.tsx`).

To view Speed Insights data:
1. Deploy your site to Vercel
2. Navigate to your project dashboard
3. Click on the "Speed Insights" tab
4. Metrics will appear after the site receives traffic
